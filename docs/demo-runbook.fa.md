# سناریوی دمو پنج‌دقیقه‌ای

## پیش از ضبط

- `.env` را با تنظیمات مدل واقعی پر کنید و `python -m src.scripts.check_llm` را اجرا کنید.
- دیتابیس را بسازید: `python -m src.scripts.load_data`.
- API و رابط را طبق README بالا بیاورید و سلامت سرویس را در نوار بالای صفحه ببینید.
- مرکز تهران را نگه دارید تا فیلترهای موقعیت به مجوز GPS وابسته نباشند.
- یک محصول از کارت‌های پیشنهاد مدل انتخاب کنید. نتیجه‌ی فروشگاه به دیتاست وابسته است؛ پیش از ضبط یک مدل با آفرهای نزدیک پیدا کنید.

## نکات ضبط

- از نام فروشگاه فقط وقتی `hasRealName` درست است استفاده کنید؛ نام‌های دیگر باید با شناسه‌ی عمومی نمایش داده شوند.
- عبارت «موجود» را از آفر دیتاست نتیجه نگیرید. پیش‌فرض همه‌ی آفرها «موجودی تأییدنشده» است.
- نقشه ممکن است به اتصال اینترنت برای کاشی‌های OpenStreetMap نیاز داشته باشد.
- اگر درخواست مدل کند شد، از رویدادهای وضعیت ابزار استفاده کنید و زمان را از فلوهای نمایشی کم کنید؛ پاسخ مدل را از قبل ضبط یا جعل نکنید.
